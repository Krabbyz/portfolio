# Personal Portfolio Website 🌐

Welcome to my personal portfolio repository! This showcases my journey as a computer science student and highlights my skills, projects, and achievements. The website is built to be interactive, responsive, and a reflection of my growth as a developer.

## 🎯 Project Goals

- **Interactive Design:** Deliver a user-friendly and visually appealing interface.
- **Responsive Layout:** Ensure compatibility across devices (desktops, tablets, and mobile phones).
- **Progress Tracking:** Document my learning journey and achievements in software engineering.

## ✨ Features

- Animated interactable landing background and automatic mobile movement
- Responsive About section with profile image, bio, and technology groups
- Project showcase with scalable screenshots, links, and skill icons
- Contact form powered by EmailJS
- Responsive navigation and custom scrollbar

## 🛠️ Technologies Used

- React 19
- Create React App / react-scripts
- EmailJS
- Ant Design Icons
- React Icons
